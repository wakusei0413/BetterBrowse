06贴心细节

那些让手感更好的小事

阈值倒计时提醒

标签页超过阈值时，页面右下角浮现倒计时卡片温柔提醒，冷却机制防止反复打扰。

右键快捷收纳

在页面或标签页上右键：收纳全部、收纳左侧、收纳右侧、打开收纳箱，一步到位。

深浅色自适应

跟随系统切换深浅配色，与 Chrome 原生界面融为一体——这个页面也一样，右上角可切换。

JSON 全量备份

收纳数据与全部插件配置一键导出为标准 JSON，换电脑、重装系统都能平滑还原。

搜索 · 星标 · 锁定

收纳箱支持实时搜索过滤，重要分组星标置顶、锁定防删、随意重命名。

智能去重与迁移

同一 URL 只收一份；存储架构版本化迁移，老数据升级无感，配置永不丢。

07立即安装

三步装好，立即可用

无需构建、无需等待商店审核——克隆仓库，加载源码目录，一分钟上手。

1

获取源码

克隆仓库到本地任意目录（或从 GitHub 下载 ZIP 解压）。

git clone https://github.com/wakusei0413/BetterBrowse.git
2

打开扩展管理页

在地址栏进入 chrome://extensions，右上角打开「开发者模式」开关。

3

加载扩展

点击「加载已解压的扩展程序」，选择项目根目录（包含 manifest.json 的那一层）。工具栏出现猫耳图标，安装完成。

开发者指令（Deno 2.x 驱动）

deno task test    # 运行全套自动化测试
deno task verify  # 静态规范与 UTF-8 校验
deno task bundle  # 重新打包内容脚本
deno task icons   # 生成全尺寸高清图标
零构建心智：源码即运行代码。修改 src/ 里的 JS / HTML / CSS 后，回到扩展管理页点一下刷新，立即生效。
08常见问题

你可能想问

会收集我的浏览数据吗？
不会。所有逻辑（规则评估、频次统计、收纳存储）都在你的设备上本地运行，扩展没有服务器、没有埋点、没有远程请求。权限仅用于标签页管理与本地存储。
会不会误收我正在用的页面？
五道保护闸依次把关：正在播放声音（P0）、表单有未保存输入（P0）、最近 5 分钟活跃（P1）、一小时高频访问前 20%（P2）、手动固定（P3）的标签页一律跳过收纳，只有真正闲置的页面才会被收走。
和 OneTab 有什么区别？
OneTab 是「点一下、收一批」的一次性工具；BetterBrowse 是常住管家——五级规则保护、阈值提醒、防误关、右键快捷收纳，并且支持与 OneTab 纯文本及内部数据双向互导，搬家零成本。
支持哪些浏览器？
基于 Chrome Extensions Manifest V3 开发，Chrome、Edge 及其他 Chromium 内核浏览器均可加载使用；暂不支持 Firefox（清单与 API 存在差异）。
如何更新版本？
在项目目录执行 git pull 拉取最新代码，然后回到扩展管理页点击刷新图标即可。内置的数据架构版本迁移器会自动完成存储升级，老数据无感保留。
